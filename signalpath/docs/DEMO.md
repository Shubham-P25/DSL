# Five-minute demo

1. Start the backend and frontend from [README.md](../README.md).
2. Paste a short public URL and inspect the metadata preview.
3. Start a job and show live segment/status events on the processing page.
4. Open results, inspect trust buckets, correction evidence, translation trust, summary grounding, and export an SRT.
5. Use review and benchmark endpoints only with real human edits or a real reference; no metric is fabricated by the application.
